## Сравнительная таблица:

| | Throttling | Debounce |
| -- | -- | -- |
| Когда использовать | Когда ванжо делать что-то с определенной периодичностью, но ограничивать частоту исполнения| Когда важно дождаться окончания череды определенных повторяющихся действий и сделать что-то после этого |
| Как работает | Устанавливает задержку для последовательного исполнения операций, аналог пинга | Устанавливает задержку тмполнения операции после последнего действия |
| Примеры применения | Скроллинг, ограничение DDOSа сервера повторяющимися запросами | Валидация ввода только когда пользователь перестав вводить данные, обработки ресайзингов |
